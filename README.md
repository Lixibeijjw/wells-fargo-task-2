# Wells Fargo Software Engineering — Task 2

This project implements the JPA data model for the second task in Forage's
Wells Fargo Software Engineering job simulation.

## Data model

- One `Advisor` manages zero or more `Client` records.
- Each `Client` belongs to one `Advisor` and owns one `Portfolio`.
- Each `Portfolio` belongs to one `Client` and contains zero or more
  `Security` records.
- Each `Security` stores a name, category, purchase date, purchase price,
  quantity, and its owning portfolio.

All entity IDs are generated by the database. Every persistent field is mapped
with a JPA column or relationship annotation, and each entity provides the
constructors, getters, and setters required by the task.
